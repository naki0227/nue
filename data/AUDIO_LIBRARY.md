# Nue asset library

All bundled sound effects and icons are original, generated by the scripts in
`scripts/`. Add your own files next to them: the file name (without extension)
is the name used in the edit plan.

## Sound effects (`data/se`, used as `se_events[].type`)

| Name | Sound | Typical use |
| --- | --- | --- |
| `impact` | deep hit | highlights, punchlines (local analyzer: loudness peaks) |
| `whoosh` | air sweep | transitions (local analyzer: scene changes) |
| `pop` | bubble pop | text or icon appearing |
| `ding` | bell | correct answer, good point |
| `boing` | cartoon spring | funny moment |
| `buzzer` | quiz buzzer | mistake, wrong answer |
| `sparkle` | glitter | reveal, "kira-kira" |
| `SYNTH_DON`, `SYNTH_WHOOSH` | legacy synth sounds | kept for older plans |

Aliases: `funny`/`laugh` → `boing`, `transition`/`swoosh` → `whoosh`,
`correct`/`bell` → `ding`, `click`/`appear` → `pop`, `fail`/`wrong` → `buzzer`,
`shine`/`magic` → `sparkle`, `serious`/`shock`/`hit` → `impact`. Unknown types fall back to `impact`.

Regenerate: `scripts/generate-sound-effects.sh` (ffmpeg only).

## Icons (`data/icons`, used as `overlays[].asset`)

`exclaim`, `question`, `heart`, `star`, `sparkle`, `sweat`, `check`, `cross`, `arrow`, `fire`
— 512x512 transparent PNGs. Regenerate: `python3 scripts/generate_icons.py` (needs Pillow).

## BGM (`data/bgm`)

`default_bgm.mp3` is used unless the plan names a track (`bgm_path`) or a file
name contains the plan's mood (for example `calm_piano.mp3` for mood `calm`).
Make sure you have the rights to any music you add.
