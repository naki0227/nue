# Nue ROIモデル

このメモの目的は、Nueを「作って楽しいAI動画編集基盤」で終わらせず、時間とお金をどれくらい削減できるかまで追えるようにすることです。

## オーバーエンジニアリング判定

現時点では、Nueはファイルベースの小さなパイプラインのままで十分です。

今は残すもの:

- `web -> data/raw -> muscle (analyze) -> data/json -> muscle (render) -> data/output` の流れ
- `data/jobs/*.json` によるジョブ状態管理
- Docker Compose と共有ボリューム

今は入れないもの:

- DBベースのジョブキュー
- Redisや分散ワーカー
- ユーザー認証、課金、マルチテナント管理
- S3/GCSなどのオブジェクトストレージ

追加する判断ライン:

- 同時レンダリングで取りこぼしが出たら、ジョブキューを入れる
- 過去ジョブの検索や分析が必要になったら、DBを入れる
- ローカルディスクがボトルネックになったら、オブジェクトストレージを入れる

つまり、次に伸ばすべきはインフラではなく、編集判断、音量、字幕、プレビュー、再レンダリング導線です。

## 前提数字

これは市場平均ではなく、Nueの価値を測るための仮置きモデルです。実績が取れたら更新します。

| シナリオ | 手作業の編集時間 | Nueでの人間の作業時間 | 機械/API待ち時間 | 人間の削減時間 |
| --- | ---: | ---: | ---: | ---: |
| ショート動画1本 | 60分 | 10分 | 10-20分 | 50分 |
| 10分尺のYouTube動画 | 120分 | 20分 | 15-30分 | 100分 |
| 30分素材からハイライト化 | 240分 | 35分 | 30-60分 | 205分 |

ローカル解析（`--analyzer local`）ならAPI費は0円で、ツール費は計算資源のみです。

機械/API待ち時間も納期には影響します。ただしコスト削減の主役は、人間が編集画面に張り付かなくてよくなる時間です。

## コスト削減モデル

計算式:

```text
1本あたり削減額 =
  (手作業分数 - Nueでの人間作業分数) / 60
  * 編集者の時間単価
  - AI/API費
  - 計算資源費
```

10分尺のYouTube動画を例にした場合:

| 編集者の時間単価 | 手作業コスト 120分 | Nueの人間作業コスト 20分 | ツール費の仮置き | 1本あたり純削減額 |
| ---: | ---: | ---: | ---: | ---: |
| 3,000円/時 | 6,000円 | 1,000円 | 100-500円 | 4,500-4,900円 |
| 5,000円/時 | 10,000円 | 1,667円 | 100-500円 | 7,833-8,233円 |
| 8,000円/時 | 16,000円 | 2,667円 | 100-500円 | 12,833-13,233円 |

月20本作る場合:

| 編集者の時間単価 | 1本あたり純削減額 | 月間純削減額 |
| ---: | ---: | ---: |
| 3,000円/時 | 4,500-4,900円 | 90,000-98,000円 |
| 5,000円/時 | 7,833-8,233円 | 156,660-164,660円 |
| 8,000円/時 | 12,833-13,233円 | 256,660-264,660円 |

## 成功指標

まず追うべき指標:

- 人間のレビュー時間: 10分尺動画で20分以下
- 再レンダリング回数: 採用動画1本あたり1.3回以下
- 手修正数: 1本あたり5箇所以下
- 1回レビュー後の採用率: 80%以上
- エンドツーエンド所要時間: 10分尺動画で45分以下

この数字を満たせない場合、インフラ追加ではなく、カット選定、音声ミックス、字幕、プレビュー/修正導線を先に改善します。
